# 业务规则

NL2SQL 相关的业务规则说明。

## 用户状态

- status = 1 表示有效用户，可以正常登录和使用系统。
- status = 0 表示禁用或未激活用户，不能登录。
- 统计"有效用户"时，条件应为 `WHERE status = 1`。

## 软删除

- is_deleted 字段用于逻辑删除。
- is_deleted = 0 表示记录未删除，是有效记录。
- is_deleted = 1 表示记录已删除。
- 所有查询默认都应加上 `WHERE is_deleted = 0` 条件。
- 如果用户问"所有人"或"所有记录"，仍然要加上 is_deleted = 0。

## 城市字段

- city 字段存储用户所在城市名称，字符串类型。
- 可用于按城市分组统计人数。
- 城市名称为中文全称，如"北京"、"上海"、"广州"。
